File format

The first sheet / header row is read; column names from AMFI exports and common CRM spellings are recognised. Each row needs a name and a valid Indian mobile number; the ARN is optional but must be valid when present.

Only the columns needed to call and empanel a distributor are kept (name, firm, ARN, EUIN, phones, email, city, state, PIN, ARN validity, language). A number on the do-not-call list is imported but stays excluded from every campaign. Existing status, opt-outs and notes are never changed by an import.
